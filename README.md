# ホップフィールドネットワークによる文字パターンの想起

> **実施時期:** 2025年7月
> **README 整理:** 2026年10月25日（就職活動での公開にあたり、README.md の整理のみを行いました。コードは実験当時のまま変更していません）

## 概要

**ホップフィールドネットワークを NumPy だけで実装**し、ノイズを加えた文字画像から元の画像をどこまで想起（復元）できるかを実験しました。

- **データ:** 5×5 ピクセル・二値（+1 / −1）の文字画像（A, B, C, D, E, F, H, Z）
- **学習:** ヘッブ則（自己相関）で重み行列を作成（対角成分は 0）
- **想起:** 次の 3 通りの更新方法を実装
  - 同期更新（ステップ数を固定）
  - 同期更新（エネルギーが変化しなくなるまで）
  - 非同期更新（ランダムに選んだ 1 ニューロンずつ更新）
- **評価指標:**
  - 正確率: 想起結果が元の画像と完全に一致した割合
  - 平均類似度: 想起結果のうち、元の画像と一致した画素の割合

考察などの詳細はレポートにまとめています。

## 実験内容

各条件で 100 回試行し、学習したパターンからランダムに 1 つ選んでノイズ（画素の反転）を加え、想起させました。

| 実験 | 内容 | 実行ファイル |
|---|---|---|
| 実験1 | 記憶させる文字数（1〜6）とノイズ率（5〜20%）を変えて、正確率・平均類似度を比較 | `examples/run_kadai1.py` |
| 実験2 | 記憶させる文字数が 2 と 4 のとき、ノイズ率 0〜100% での性能の変化をグラフ化 | `examples/run_kadai2.py` |
| 実験3 | 想起の更新方法（同期・非同期）による違いを比較 | `examples/run_kadai1.py` の想起方法を切り替えて実施 |
| 実験4 | 8 文字から 3 文字を選ぶ全 56 通りの組み合わせで性能を比較し、覚えやすい組み合わせを調査 | `examples/run_kadai4.py` |

## 使用技術

- Python
- NumPy（ネットワークの実装）
- matplotlib（画像・グラフの表示）

## ディレクトリ構成

```
hopfield_network/
├── hopfield/
│   ├── network.py        # ホップフィールドネットワーク本体（学習・想起・エネルギー計算）
│   └── utils.py          # ノイズ付加、評価、画像表示などの関数
├── data/
│   └── data.py           # 文字画像（5×5）のデータ
└── examples/
    ├── run_example.py    # 動作確認用（A と C を学習し、ノイズを加えた A を想起）
    ├── run_kadai1.py     # 実験1（実験3にも使用）
    ├── run_kadai2.py     # 実験2（結果を kadai2.png に保存）
    ├── run_kadai4.py     # 実験4
    └── show_images.py    # 文字画像の一覧を表示
```

## 実行方法

NumPy と matplotlib が必要です。

```bash
pip install numpy matplotlib
```

リポジトリのルートで実行します。

```bash
python examples/run_example.py
python examples/run_kadai1.py
python examples/run_kadai2.py
python examples/run_kadai4.py
python examples/show_images.py
```
